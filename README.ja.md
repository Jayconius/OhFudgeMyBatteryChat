ヘッドセット、コントローラー、トラッカーのバッテリー残量を配信中にリアル
タイム表示し、残量が少なくなるとポップイン通知を出します - 通常のOBS
ブラウザソースとして動作します。

> [!TIP]
> **配信していない方へ**: OBSは不要です - アプリ内の**ブラウザで開く**を
> クリックすれば、単体のバッテリー低下アラームとして使えます。

## クイックスタート

1. [Releases](https://github.com/Jayconius/OhFudgeMyBatteryChat/releases/latest)
   からexeを取得し、**SteamVR**を先に起動した状態で実行します。
2. **追加**をクリックしてデバイス表示や低バッテリーアラートを追加し、
   ドラッグして配置します。
3. 上部に表示されているURLをOBSに**ブラウザソース**としてコピーします
   （サイズ 1920x1080）。

これだけです - Pythonや追加インストールは不要で、exe単体で完結します。

## 使い方ガイド

> [!NOTE]
> **一部のデバイスはバッテリー状態をまとめて更新し、連続的には更新しま
> せん。** 特に一部のトラッカーは、電源を入れ直すか実際にバッテリーが
> 低下するまで**「n/a」**と表示されることがあります。これはそのデバイス
> 自身のドライバーの仕様であり、このアプリの不具合ではありません -
> 他のデバイスが正しくデータを表示していれば問題なく、そのデバイスも
> ドライバーが報告するタイミングで実際のデータが表示されるようになり
> ます。

<details>
<summary><strong>OBSブラウザソースの追加</strong></summary>

1. OBSで: **ソース > + > ブラウザ**、名前を付けてOKをクリックします。
2. アプリ上部に表示されているURLを貼り付けます（デフォルトは
   `http://127.0.0.1:8710/overlay`）。
3. **幅**を`1920`、**高さ**を`1080`に設定します。項目の*位置*はどの
   キャンバスサイズにも問題なく拡大縮小されますが、項目の*サイズ*は
   位置エディタ内でこの1920x1080を基準に調整されているため、プレビュー
   で見た大きさのまま表示されるようこの解像度に合わせてください。
4. シーンが表示されていない間もバッテリー低下アラートを動作させたい
   場合は、**「非表示時にソースを停止」**のチェックを外したままにして
   ください。
5. 警告音が再生されない場合は、このソースの**「OBS経由で音声を制御」**
   オプションを確認してください - OBSのバージョンによっては自動再生
   音声をこの設定でブロックすることがあります。

</details>

<details>
<summary><strong>デバイスの追加（リアルタイムバッテリー表示）</strong></summary>

1. **追加 > デバイスを追加**をクリックします。
2. 左側のリストからデバイスを選びます（表示されない場合は**更新**を
   クリック）。
3. ラベルと低バッテリーのしきい値（%）を設定します。
4. **常に表示**（アイコンは常に表示され、低下時に画像だけが切り替わる）
   か、**低下時のみ表示**（低下時にのみポップインする）を選びます。
5. **画像とサウンド**: 通常時の画像、低下時の画像、警告音を選びます -
   いずれも省略した場合は内蔵のデフォルトが使われます。**選択...**を
   クリックすると、アプリに同梱されたヘッドセット/コントローラー/
   トラッカーのイラスト集`Data\assets\device icons`が直接開きます -
   その中から選ぶか、自分の画像/GIF/WebMを参照してください。
6. **画像アニメーション**: 通常時・低下時の画像それぞれに、静止画が
   単調にならないようWobble（揺れ）/Shake（振動）/Pulse（脈動）の
   待機アニメーションを設定できます。低下時の画像にアニメーションを
   選ぶと、自動の赤い点滅グローの代わりに使われます。
7. **ラベル文字 / バッテリー%文字**: それぞれ独立したフォント、サイズ、
   色、アニメーション、縁取りを設定できます。
8. **アニメーション**: 「低下時のみ表示」を選んだ場合、ポップイン・
   ポップアウトの方法を選び、保存前に**アニメーションをテスト**で確認
   してください。
9. **配置**: プレビューキャンバス上でドラッグして配置します - 既に
   配置済みの項目とスナップして揃います。
10. **保存**をクリックします。

</details>

<details>
<summary><strong>オーバーレイ効果の追加（単体のアラート）</strong></summary>

1. **追加 > オーバーレイ効果を追加**をクリックします。
2. **対象**: **特定のデバイス**、または**すべてのデバイス**（複数選択
   リストから任意のデバイスを除外可能）。
3. **トリガー**: バッテリー低下、バッテリー正常、デバイス切断、または
   デバイス接続。
4. **画像とサウンド**: アラート用の画像（またはGIF/動画）とサウンドを
   選びます。どちらか一方を空欄のままにするとデフォルトが使われます。
5. **キャプション文字**（任意）: メッセージを入力し、画像に対する位置、
   フォント、サイズ、色、縁取り、wobble/shake/pulseアニメーションを
   設定します。
6. **アニメーション**: アラートのポップイン・ポップアウトの方法を選び、
   保存前に**アニメーションをテスト**で確認してください。
7. **配置**: デバイスと同様のスナップ機能でドラッグして配置します。
8. **保存**をクリックします。

</details>

## 機能

- 任意のSteamVRデバイスのバッテリー%をリアルタイム表示し、低下時には
  ポップイン通知
- 独自の画像/GIF/動画とサウンドを使用可能。加えて同梱のイラスト付き
  デバイス素材集、または内蔵のデフォルトも利用可能
- ラベル文字、バッテリー%文字、オーバーレイ効果のキャプションそれぞれに
  独立したフォント/サイズ/色/アニメーション/縁取りのカスタマイズ
- デバイス画像向けの任意の待機アニメーション（Wobble/Shake/Pulse）
- スナップ位置合わせ付きのドラッグ配置、複数のポップイン/フェード
  アニメーション
- Nudge Groupsにより複数の低バッテリーアラートが重ならないよう自動的に
  整列（古いものから順に）
- 起動時の新バージョン確認（任意、デフォルトは無効）
- 英語、ドイツ語、フランス語、スペイン語、日本語、クリンゴン語に対応

## ソースからのビルド

```bash
pip install -r requirements.txt
pyinstaller --onefile --windowed --name "OhFudgeMyBatteryChat" --collect-all openvr --add-data "app/fonts;fonts" --add-data "assets;device_icons" main.py
```
